# M0-02 — Continuous Integration

Stato: implementata localmente; da validare su GitHub Actions dopo il push.

## Pipeline
- Backend: Java 21, Maven `verify` (test inclusi).
- Frontend: Node 22, `npm ci`, `npm test`, `npm run build`.
- Igiene repository: verifica che `.env` e cartelle generate non siano versionate.
- Trigger: push su `main` o branch `feature/**`; pull request verso `main`.
- Permessi GitHub Actions limitati a `contents: read`.

## Comandi locali
Da `~/Develop/penny`:

```bash
docker compose run --rm backend mvn -B -ntp verify
docker compose run --rm frontend npm test
docker compose run --rm frontend npm run build
```

## Limiti e passi successivi
- I test correnti sono smoke test; non sostituiscono test di integrazione con PostgreSQL.
- Nessun secret richiesto nella pipeline.
- Aggiungere Dependabot, scanning dipendenze e branch protection dopo validazione della CI.
- Le specifiche funzionali originali complete devono essere reintegrate prima di M1.
